# Implementation Plan

## Phase 5.1 — initialization and data validation

Create Vite/React/strict TypeScript project; copy generated JSON; define domain types, runtime parser, indexes, fixtures, and data tests.

## Phase 5.2 — responsive application shell

Implement route model, shell, desktop rail, mobile bottom nav/drawer, design tokens, accessible primitives, dashboard, error states, and shell tests.

## Phase 5.3 — study library

Implement term/subject/chapter/topic/glossary/source views, bilingual search, chapter bookmarks, and library tests.

## Phase 5.4 — practice engine

Implement filters, seeded randomization, feedback modes, choice submission, incorrect/unanswered/bookmarked queues, and scoring/visibility tests.

## Phase 5.5 — mock examination

Implement configuration, active exam reducer, optional timer, navigator, confirmation, results, subject/topic scoring, answer review, and timer/no-leakage tests.

## Phase 5.6 — progress and bookmarks

Implement versioned local persistence, attempt history, topic/subject performance, weak topics, question bookmarks, reset confirmation, and persistence tests.

## Phase 5.7 — responsive polish and accessibility

Audit every required viewport; fix overflow, sticky/drawer/dialog behavior, touch sizing, focus order, semantics, contrast, reduced motion, and Thai wrapping.

## Phase 5.8 — complete verification

Run academic validation, lint, type check, all unit/integration/browser tests, dependency audit, production build, and preview smoke test; record exact results.

Every subphase updates `TASKS.md`, `PROJECT_STATE.md`, and the phase report. Git commits remain unavailable until a repository exists.
