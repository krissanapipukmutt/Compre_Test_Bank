# LAN, backbone, WAN, Internet, and network management

## LAN, Backbone, WAN, Internet และการจัดการเครือข่าย

### Concise summary

LANs connect local devices, backbones aggregate segments, WANs span locations, the Internet interconnects networks, and management observes and controls service health.

### สรุปภาษาไทย

LAN เชื่อมอุปกรณ์ในพื้นที่ Backbone รวม Segment, WAN เชื่อมพื้นที่ห่างไกล, Internet เชื่อมเครือข่าย และการจัดการติดตาม/ควบคุมสุขภาพบริการ

### Technical terms and definitions

- **LAN / เครือข่ายท้องถิ่น** — A network serving devices within a limited area.  
  เครือข่ายที่ให้บริการอุปกรณ์ในพื้นที่จำกัด
- **WAN / เครือข่ายบริเวณกว้าง** — A network or service connecting geographically separated sites.  
  เครือข่ายหรือบริการที่เชื่อมสถานที่ห่างกัน
- **Network management / การจัดการเครือข่าย** — Configuration, monitoring, fault, performance, and security activities.  
  กิจกรรมด้าน Configuration, Monitoring, Fault, Performance และ Security
