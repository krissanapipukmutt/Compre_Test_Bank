# Network communication foundations

## พื้นฐานการสื่อสารเครือข่าย

### Concise summary

Network communication is organized in layers that define services, protocols, encapsulation, addressing, and physical transmission.

### Technical terms and definitions

- **Protocol / โพรโทคอล** — Rules and message formats used by communicating entities.  
  กฎและรูปแบบข้อความที่หน่วยสื่อสารใช้ร่วมกัน
- **Encapsulation / การห่อหุ้มข้อมูล** — Each layer adds control information around higher-layer data.  
  แต่ละชั้นเพิ่มข้อมูลควบคุมรอบข้อมูลจากชั้นบน
- **Transmission medium / สื่อส่งสัญญาณ** — The physical path carrying electrical, optical, or radio signals.  
  เส้นทางกายภาพที่นำสัญญาณไฟฟ้า แสง หรือวิทยุ
