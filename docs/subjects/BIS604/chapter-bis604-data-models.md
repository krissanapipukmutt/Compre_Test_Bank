# Data models

## แบบจำลองข้อมูล

### Concise summary

A data model provides concepts and rules for describing entities, relationships, constraints, and operations at conceptual, logical, and physical levels.

### Technical terms and definitions

- **Conceptual model / แบบจำลองเชิงแนวคิด** — A technology-independent business view of data and relationships.  
  มุมมองข้อมูลและความสัมพันธ์ทางธุรกิจที่ไม่ผูกเทคโนโลยี
- **Logical model / แบบจำลองเชิงตรรกะ** — A detailed structure for a model type, independent of a specific storage product.  
  โครงสร้างละเอียดตามชนิดโมเดลโดยไม่ผูกผลิตภัณฑ์จัดเก็บ
- **Physical model / แบบจำลองเชิงกายภาพ** — Implementation structures optimized for a specific DBMS.  
  โครงสร้างนำไปใช้ที่ปรับให้เหมาะกับ DBMS เฉพาะ
