# BIS604 — Business Data Management

## ชื่อวิชา

การจัดการข้อมูลธุรกิจ

## Subject overview

BIS604 develops database literacy from data-management foundations and data models through relational design, business rules, ER modeling, normalization, SQL implementation, and business use.

## ภาพรวมรายวิชา

BIS604 พัฒนาความรู้ฐานข้อมูลตั้งแต่พื้นฐานการจัดการข้อมูลและแบบจำลองข้อมูล ผ่านการออกแบบเชิงสัมพันธ์ กฎธุรกิจ ER การทำ Normalization การใช้ SQL และการนำข้อมูลไปใช้ในธุรกิจ

## Learning objectives

- Explain database systems and data-model tradeoffs.
- Transform business rules into relational and ER designs.
- Normalize and implement a database with SQL.

## วัตถุประสงค์การเรียนรู้

- อธิบายระบบฐานข้อมูลและข้อแลกเปลี่ยนของแบบจำลองข้อมูล
- แปลงกฎธุรกิจเป็นแบบเชิงสัมพันธ์และ ER
- ทำ Normalization และสร้างฐานข้อมูลด้วย SQL
