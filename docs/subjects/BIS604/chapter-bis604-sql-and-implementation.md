# SQL and database implementation

## SQL และการสร้างฐานข้อมูล

### Concise summary

SQL defines schema and constraints, changes stored data, and retrieves it through selection, projection, joins, grouping, expressions, and transactions.

### สรุปภาษาไทย

SQL กำหนด Schema/Constraint เปลี่ยนข้อมูล และสืบค้นด้วย Selection, Projection, Join, Grouping, Expression และ Transaction

### คำอธิบายโดยละเอียด

SQL กำหนด Schema/Constraint เปลี่ยนข้อมูล และสืบค้นด้วย Selection, Projection, Join, Grouping, Expression และ Transaction ให้เริ่มจากวัตถุประสงค์ทางธุรกิจ ระบุข้อมูลหรือเงื่อนไขที่ต้องใช้ เลือกแนวคิดหรือขั้นตอนให้ตรงกับโจทย์ ตรวจสมมติฐาน แล้วสื่อความหมายของผลลัพธ์และข้อจำกัดอย่างชัดเจน

### Technical terms and definitions

- **DDL / ภาษากำหนดข้อมูล** — SQL statements that create or alter database structures and constraints.  
  คำสั่ง SQL ที่สร้างหรือแก้โครงสร้างและ Constraint
- **DML / ภาษาจัดการข้อมูล** — SQL statements that insert, update, delete, and query data.  
  คำสั่ง SQL สำหรับ Insert, Update, Delete และ Query
- **Join / การเชื่อมตาราง** — Combine rows from related tables using a condition.  
  รวมแถวจากตารางที่เกี่ยวข้องด้วยเงื่อนไข
