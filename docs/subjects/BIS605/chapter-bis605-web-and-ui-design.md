# Web and interface design principles

## หลักการออกแบบเว็บและส่วนติดต่อ

### Concise summary

Good interfaces align information hierarchy, consistency, feedback, error prevention, accessibility, and responsive behavior with user tasks.

### Technical terms and definitions

- **Visual hierarchy / ลำดับชั้นทางสายตา** — Use size, contrast, space, and position to communicate importance.  
  ใช้ขนาด ความต่าง พื้นที่ว่าง และตำแหน่งเพื่อสื่อความสำคัญ
- **Usability / ความสามารถในการใช้งาน** — Effectiveness, efficiency, and satisfaction for intended users.  
  ประสิทธิผล ประสิทธิภาพ และความพึงพอใจของผู้ใช้เป้าหมาย
- **Prototype / ต้นแบบ** — A testable representation used to learn before full implementation.  
  ตัวแทนที่ทดสอบได้เพื่อเรียนรู้ก่อนพัฒนาจริงเต็มรูปแบบ
