# Back-end, database, API, cloud, and mobile technologies

## Back-end ฐานข้อมูล API Cloud และ Mobile

### Concise summary

Server-side logic validates requests and coordinates data; databases persist state; APIs define contracts; cloud and mobile technologies shape deployment and client constraints.

### Technical terms and definitions

- **Server-side validation / การตรวจสอบฝั่งเซิร์ฟเวอร์** — Validate untrusted input where policy and data are controlled.  
  ตรวจ Input ที่ไม่เชื่อถือในจุดที่ควบคุมนโยบายและข้อมูล
- **API contract / สัญญา API** — An agreed request, response, error, and behavior interface.  
  ข้อตกลงของ Request, Response, Error และพฤติกรรม
- **Cloud service model / รูปแบบบริการคลาวด์** — A division of responsibility for infrastructure, platform, or software services.  
  การแบ่งความรับผิดชอบสำหรับบริการ Infrastructure, Platform หรือ Software
