# BIS605 — Software Development Technologies for Digital Business

## ชื่อวิชา

เทคโนโลยีการพัฒนาซอฟต์แวร์สำหรับธุรกิจดิจิทัล

## Subject overview

BIS605 covers the software lifecycle and design foundations, then applies them through front-end, back-end, database, API, cloud, and mobile technologies for digital-business solutions.

## ภาพรวมรายวิชา

BIS605 ครอบคลุมวงจรชีวิตและพื้นฐานการออกแบบซอฟต์แวร์ แล้วนำไปประยุกต์ผ่านเทคโนโลยี Front-end, Back-end, ฐานข้อมูล, API, Cloud และ Mobile สำหรับโซลูชันธุรกิจดิจิทัล

## Learning objectives

- Relate architecture, lifecycle, requirements, and design decisions.
- Build accessible interfaces with core web technologies.
- Explain server, database, API, cloud, and mobile integration.

## วัตถุประสงค์การเรียนรู้

- เชื่อมการตัดสินใจด้านสถาปัตยกรรม วงจรชีวิต ความต้องการ และการออกแบบ
- สร้างส่วนติดต่อที่เข้าถึงได้ด้วยเทคโนโลยีเว็บหลัก
- อธิบายการเชื่อม Server, Database, API, Cloud และ Mobile

- [System architecture and software lifecycle](chapter-bis605-architecture-and-sdlc.md) — สถาปัตยกรรมระบบและวงจรชีวิตซอฟต์แวร์
- [Software design and requirements](chapter-bis605-software-design.md) — การออกแบบซอฟต์แวร์และความต้องการ

- [Frameworks and development technologies](chapter-bis605-development-technologies.md) — เฟรมเวิร์กและเทคโนโลยีการพัฒนา

- [Back-end, database, API, cloud, and mobile technologies](chapter-bis605-backend-data-api-cloud-mobile.md) — Back-end ฐานข้อมูล API Cloud และ Mobile
