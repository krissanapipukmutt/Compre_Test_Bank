# System architecture and software lifecycle

## สถาปัตยกรรมระบบและวงจรชีวิตซอฟต์แวร์

### Concise summary

Architecture describes components, responsibilities, and interactions; the lifecycle organizes how a team discovers, designs, builds, tests, deploys, and evolves the solution.

### Technical terms and definitions

- **Layered architecture / สถาปัตยกรรมแบบแบ่งชั้น** — Separates presentation, application, domain, and data responsibilities.  
  แยกความรับผิดชอบด้านการนำเสนอ แอปพลิเคชัน โดเมน และข้อมูล
- **Software lifecycle / วงจรชีวิตซอฟต์แวร์** — Activities that govern a software product from idea through operation.  
  กิจกรรมที่กำกับผลิตภัณฑ์ซอฟต์แวร์ตั้งแต่แนวคิดถึงการปฏิบัติการ
- **Iterative delivery / การส่งมอบแบบวนรอบ** — Build and evaluate increments to reduce uncertainty early.  
  สร้างและประเมินส่วนเพิ่มเพื่อลดความไม่แน่นอนตั้งแต่ต้น
