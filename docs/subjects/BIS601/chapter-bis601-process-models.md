# Data-flow and decision modeling

## การสร้างแบบจำลองการไหลของข้อมูลและการตัดสินใจ

### Concise summary

DFDs separate processes, flows, stores, and external entities; decision models make conditional business logic complete and testable.

### สรุปภาษาไทย

DFD แยก Process, Data Flow, Data Store และ External Entity ส่วนแบบจำลองการตัดสินใจทำให้ตรรกะเงื่อนไขครบถ้วนและทดสอบได้

### คำอธิบายโดยละเอียด

DFD แยก Process, Data Flow, Data Store และ External Entity ส่วนแบบจำลองการตัดสินใจทำให้ตรรกะเงื่อนไขครบถ้วนและทดสอบได้ ให้เริ่มจากวัตถุประสงค์ทางธุรกิจ ระบุข้อมูลหรือเงื่อนไขที่ต้องใช้ เลือกแนวคิดหรือขั้นตอนให้ตรงกับโจทย์ ตรวจสมมติฐาน แล้วสื่อความหมายของผลลัพธ์และข้อจำกัดอย่างชัดเจน

### Technical terms and definitions

- **Data-flow diagram / แผนภาพการไหลของข้อมูล** — A logical model of how data enters, is transformed, stored, and leaves a system.  
  แบบจำลองเชิงตรรกะว่าข้อมูลเข้าสู่ระบบ ถูกแปลง จัดเก็บ และออกจากระบบอย่างไร
- **Balancing / การสมดุล DFD** — Inputs and outputs remain consistent across decomposition levels.  
  ข้อมูลเข้าและออกต้องสอดคล้องกันระหว่างระดับการแตกกระบวนการ
- **Decision table / ตารางการตัดสินใจ** — A tabular representation of condition combinations and resulting actions.  
  ตารางแสดงชุดเงื่อนไขและการกระทำที่เกิดขึ้น
