# Activity and use-case modeling

## การสร้างแบบจำลองกิจกรรมและกรณีใช้งาน

### Concise summary

Activity models show workflow, while use cases describe goal-oriented interactions between actors and the system boundary.

### สรุปภาษาไทย

Activity Diagram แสดงลำดับงาน ส่วน Use Case อธิบายปฏิสัมพันธ์ที่มุ่งเป้าหมายระหว่าง Actor กับขอบเขตระบบ

### คำอธิบายโดยละเอียด

Activity Diagram แสดงลำดับงาน ส่วน Use Case อธิบายปฏิสัมพันธ์ที่มุ่งเป้าหมายระหว่าง Actor กับขอบเขตระบบ ให้เริ่มจากวัตถุประสงค์ทางธุรกิจ ระบุข้อมูลหรือเงื่อนไขที่ต้องใช้ เลือกแนวคิดหรือขั้นตอนให้ตรงกับโจทย์ ตรวจสมมติฐาน แล้วสื่อความหมายของผลลัพธ์และข้อจำกัดอย่างชัดเจน

### Technical terms and definitions

- **Activity diagram / แผนภาพกิจกรรม** — A behavioral model of actions, decisions, parallel paths, and flow.  
  แบบจำลองพฤติกรรมของกิจกรรม การตัดสินใจ เส้นทางขนาน และการไหล
- **Actor / ผู้กระทำ** — An external role that interacts with a system to achieve a goal.  
  บทบาทภายนอกที่โต้ตอบกับระบบเพื่อบรรลุเป้าหมาย
- **Use case / กรณีใช้งาน** — A sequence of interactions that delivers observable value to an actor.  
  ลำดับปฏิสัมพันธ์ที่ส่งมอบคุณค่าที่สังเกตได้ให้ Actor
