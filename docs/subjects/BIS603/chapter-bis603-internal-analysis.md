# Internal strategic analysis

## การวิเคราะห์กลยุทธ์ภายใน

### Concise summary

Internal analysis evaluates resources, capabilities, processes, culture, cost drivers, and distinctive strengths that can support advantage.

### Technical terms and definitions

- **Resource / ทรัพยากร** — An asset available to the organization.  
  สินทรัพย์ที่องค์กรนำมาใช้ได้
- **Capability / ความสามารถองค์กร** — A repeatable ability to coordinate resources and perform activities.  
  ความสามารถทำซ้ำในการประสานทรัพยากรและดำเนินกิจกรรม
- **VRIO / กรอบ VRIO** — Tests whether resources are valuable, rare, hard to imitate, and organizationally supported.  
  ทดสอบว่าทรัพยากรมีคุณค่า หายาก เลียนแบบยาก และองค์กรรองรับหรือไม่
