# Enterprise data management

## การจัดการข้อมูลองค์กร

### Concise summary

Enterprise data management coordinates data sources, quality, integration, governance, and lifecycle so analytics uses consistent and trustworthy data.

### Technical terms and definitions

- **Data quality / คุณภาพข้อมูล** — Fitness for use across accuracy, completeness, consistency, timeliness, and validity.  
  ความเหมาะสมต่อการใช้งานด้านความถูกต้อง ครบถ้วน สอดคล้อง ทันเวลา และเป็นไปตามกฎ
- **ETL / กระบวนการ ETL** — Extract data, transform it to agreed rules, and load it into a target.  
  ดึงข้อมูล แปลงตามกฎที่ตกลง และโหลดเข้าสู่ปลายทาง
- **Data governance / ธรรมาภิบาลข้อมูล** — Decision rights, accountability, standards, and controls for data.  
  สิทธิในการตัดสินใจ ความรับผิดชอบ มาตรฐาน และการควบคุมข้อมูล
