# Regression

## การวิเคราะห์การถดถอย

### Concise summary

Regression estimates a numeric outcome from explanatory variables and requires interpretation of coefficients, fit, residuals, and assumptions.

### สรุปภาษาไทย

Regression ประมาณค่าผลลัพธ์เชิงตัวเลขจากตัวแปรอธิบาย และต้องตีความสัมประสิทธิ์ ความพอดี Residual และสมมติฐาน

### คำอธิบายโดยละเอียด

Regression ประมาณค่าผลลัพธ์เชิงตัวเลขจากตัวแปรอธิบาย และต้องตีความสัมประสิทธิ์ ความพอดี Residual และสมมติฐาน ให้เริ่มจากวัตถุประสงค์ทางธุรกิจ ระบุข้อมูลหรือเงื่อนไขที่ต้องใช้ เลือกแนวคิดหรือขั้นตอนให้ตรงกับโจทย์ ตรวจสมมติฐาน แล้วสื่อความหมายของผลลัพธ์และข้อจำกัดอย่างชัดเจน

### Technical terms and definitions

- **Dependent variable / ตัวแปรตาม** — The numeric outcome a regression model explains or predicts.  
  ผลลัพธ์เชิงตัวเลขที่แบบจำลองอธิบายหรือพยากรณ์
- **Coefficient / สัมประสิทธิ์** — The estimated change in outcome associated with a predictor, conditional on the model.  
  การเปลี่ยนแปลงผลลัพธ์โดยประมาณที่สัมพันธ์กับตัวแปรอธิบายภายใต้แบบจำลอง
- **Residual / ค่าคลาดเคลื่อนคงเหลือ** — Observed outcome minus the model prediction.  
  ผลลัพธ์จริงลบค่าที่แบบจำลองพยากรณ์
